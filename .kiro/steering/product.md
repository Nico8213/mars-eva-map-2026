# Product: Martian Map (NASA Space Apps 2026)
- A map prototype for Mars extravehicular activity (EVA). Study area: Jezero crater.
- Core idea: every map layer explains where its data comes from, which version it is, how accurate it is and what its known problems are. The app also shows how data changes route decisions.
- Feature IDs are in internal/PRD_v0.3.html (a local file, not uploaded): F1 layers, F2 points of interest, F3 route, F7 validation, F8 data cards, F9 environment reference, F10 comparison, F11 reproducibility, F6 concept pages.
- Out of scope: online server computation, live data, Earth base maps, numbers without a source.
