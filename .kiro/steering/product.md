# Product: JezeroTrace (NASA Space Apps 2026)
- A map prototype for Mars extravehicular activity (EVA). Study area: Jezero crater.
- Core idea: every map layer explains where its data comes from, which version it is, how accurate it is and what its known problems are. The app shows four precomputed routes (slope constraint only), and the repository checks the route logic against the path Perseverance drove.
- Feature numbering used in the .kiro specs and the AI logs: F1 layers, F2 points of interest, F3 route, F7 validation, F8 data cards, F9 environment reference, F10 comparison, F11 reproducibility, F6 concept pages. The original requirements document is a local file that is not in this repository.
- Out of scope: online server computation, live data, Earth base maps, spectral layers, tablet and HUD apps, numbers without a source.
