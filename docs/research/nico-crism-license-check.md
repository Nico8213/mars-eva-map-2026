# Research card: CRISM data compared with the Space Apps rules
- Finding: The Space Apps legal page requires third-party materials to be freely and publicly available without restriction, or at least licensed as open source (OSI). Solutions without proper license documentation are not accepted, and every source used must be cited, even open or free ones. For CRISM data archived at the PDS, the statements found are consistent with this: PDS data sets are classified TSPA (publicly available); the PDS Geosciences Node metadata for a CRISM DDR coverage file says there are no access or use limits; JPL-supplied PDS data may be used by anyone for any purpose without prior permission, subject to the JPL policy; and PDS asks that data sets be cited like published research. No conflict with the Space Apps rules was found for PDS-archived CRISM data.
- Source URL: https://www.spaceappschallenge.org/legal (Space Apps rules); https://pds-geosciences.wustl.edu/faq.html (TSPA and citation statement); https://pds-geosciences.wustl.edu/geocopy/test/ddr/mars_mro_crism_ddr_na.shp.xml (use-limit statement for one CRISM metadata file); https://pds-geosciences.wustl.edu/jplcopyright.html (JPL policy); https://pds.nasa.gov/datastandards/citing (how to cite)
- Organization / author: NASA Space Apps Challenge; NASA PDS Geosciences Node (Washington University in St. Louis); JPL
- Version / date: Space Apps legal page shows no version; PDS Geosciences FAQ shows "last updated" December 2019; the metadata file was generated 2025-02-06
- Accessed on: 2026-11-14
- License: No access or use restrictions stated by PDS for CRISM data; attribution to the data provider and PDS expected. This is a comparison of public rules, not legal advice.
- Confidence: medium. No single page says "CRISM license: X". The "no use limits" statement is for a coverage metadata file, not for the CRISM data products themselves.
